
  # MicroHealth Design System

  This is a code bundle for MicroHealth Design System. The original project is available at https://www.figma.com/design/ZiAPik7IgtRfal3hy1ViXP/MicroHealth-Design-System.

  ## Project summary

  MicroHealth is a Point-of-Care (POC) network making primary healthcare close, affordable, and accessible to everyday Nigerians. This bundle includes a marketing site (landing + about, solution, pricing, partners, contact, and investor pitch pages), a staff/admin dashboard demo, and a patient portal demo.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  Run `npm run build` to create a production build.
